# TAMKEEN Enterprise Architecture

## Overview
TAMKEEN is a financial platform built using a microservice architecture.

### Core Services
- API Gateway
- Auth Service
- User Service
- Wallet Service
- Ledger Service
- Transfer Service

### Infrastructure
- PostgreSQL
- Prisma ORM
- Docker Compose
- TypeScript
- Express.js

### Future Modules
- Agent Network
- Merchant Network
- Exchange Engine
- Accounting Engine
- Audit Engine
- Notification Service

## Target Architecture
Client -> API Gateway -> Services -> PostgreSQL
